**Task:** Regenerate `docs/prototypes/index.html` listing all features that have a prototype.

**No arguments required.**

**Steps:**
1. Scan `docs/features/*/prototypes/index.html` — collect all that exist.
2. For each, read the parent feature's SPEC.md frontmatter:
   - Feature name (first `# ` heading in SPEC.md)
   - `Prototype:` field value (expected: `generated`, `approved`, `required`, or `N/A`)
3. Build an HTML index page listing all features with prototypes.

**Output file:** `docs/prototypes/index.html`

**Page requirements:**
- Use Tailwind CSS CDN for styling.
- Each feature entry shows: feature name, prototype status badge, link to `../features/<slug>/prototypes/index.html`.
- Status badge colors: `generated` = blue, `approved` = green, `required` = yellow (prototype exists but status not updated — warn).
- Page title: `Prototypes — <repo name from CLAUDE.md or cwd basename>`
- List is sorted alphabetically by feature slug.
- Include a footer: `Generated by /vskit:gen-prototype-index on <date>`

**If no prototype index files found:** generate a minimal page with message: "No prototypes generated yet. Run `/vskit:prototype <slug>` to generate one."

**If `docs/prototypes/` does not exist:** create it before writing.

**Print after writing:**
```
Regenerated: docs/prototypes/index.html  (<N> features listed)
```

**Writes:** `docs/prototypes/index.html`.
